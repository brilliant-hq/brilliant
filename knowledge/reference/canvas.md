# Canvas

Each part has its own key:

- `reference/canvas/zoom`: zoom shortcuts, zoom behavior, zoom to content
- `reference/canvas/scroll`: scroll and trackpad, the zoom percentage, Disable Zoom Out
- `reference/canvas/pan`: panning (Hand, Space, trackpad, scroll wheel, middle mouse) and the coordinate spaces
- `reference/canvas/hit-testing`: hit test rules per element type, selection rectangles, the marquee
- `reference/canvas/cursors`: keyboard selection navigation, nudge, cursor states, highlights
- `reference/canvas/blend`: blend modes at four scopes, rendering performance
- `reference/canvas/snapping`: how snapping works, snap types, what is offered as a snap target
- `reference/canvas/snap-toggles`: per-parent snapping, holding Cmd to place freely, toggling snaps
- `reference/canvas/measurement`: Alt+hover measurement overlays
- `reference/canvas/background`: the background layer stack and background modes
- `reference/canvas/window-modes`: studio and overlay, window and chrome toggles, agent cursors
- `reference/canvas/rulers`: rulers and ruler guides, dimension labels, the pixel grid overlay
- `reference/canvas/pixel-snap`: snap to pixel grid

Layout grids (per-frame snap targets, Shift+G) live in `reference/layout-guides`.

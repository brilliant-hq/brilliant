# Canvas: Window Modes

### Window Modes

| Mode | Description |
|------|-------------|
| Studio (default) | Regular desktop window: title bar, shadow, resizable, visible in Dock. Launches on startup. |
| Overlay | Fullscreen transparent layer above other apps: borderless, always-on-top, hidden from Dock. |

Overlay mode is **opt-in** and **macOS-focused** (the `toggle_overlay_mode` and `toggle_pass_through` shortcuts are disabled on Windows; reach them via menus/palette). Until the user enables it (Settings: "Overlay Mode"), the global hotkey is not registered. Once enabled, **Ctrl+F** toggles between studio and overlay mode. The hotkey fires even when Brilliant is unfocused, minimized, or invisible. Studio window state (position, size, fullscreen, maximized) is saved on entering overlay and restored on exit.

| Action | Shortcut | Notes |
|--------|----------|-------|
| Toggle overlay mode | Ctrl+F | Global hotkey; macOS-focused, disabled on Windows |
| Toggle passthrough | Ctrl+A | Overlay only: pointer events pass through to apps below |
| Toggle presentation mode | Alt+P | Hides the on-canvas editing chrome (selection, resize and rotate handles, gradient controls, hover cues) so a recording reads clean; the panels stay. To hide the panels use Cmd+\ (Toggle UI) or Cmd+Shift+\ (AI focus) below. |
| Toggle agent cursors | (none) | Named cursors for the user and AI agents (palette: "Toggle Agent Cursors"; Settings → Models) |
| Toggle UI (all chrome) | Cmd+\ | Hide/show ALL app chrome: the left, right, and bottom toolbars AND the top strip (the top bar with home and the tabs). Summoned surfaces stay reachable (palette, tooltips, notifications), and pressing Cmd+\ again (or the Show UI button in the corner) brings everything back as it was, in AI focus or the full UI. |
| Toggle AI focus | Cmd+Shift+\ | Switch between AI focus (the top bar, the bottom toolbar with a shorter tool set, and the AI chat; no side panels) and the full UI, where each panel can still be collapsed on its own. The Focus / Full switch in the top bar, just left of the people in the project, does the same; in AI focus the switch is the only control at the bar's right end (no people, notifications bell, Share or zoom readout; notifications still pop up, and Full brings them all back), and a panel shortcut (Cmd+Shift+Left / Right / Down) in AI focus switches to the full UI with that panel shown. In the browser editor AI focus shows one rounded control at the canvas's top-left corner: the Focus / Full switch, then the same file switcher and agent bars as the desktop's (below). In the full UI the switch leads the right panel's top row, before the zoom readout and Share (the zoom readout is left out at Compact density and while Share's place shows Save a copy or Open fullscreen, and Share is left out when signed out); with the right panel collapsed, the switch alone sits at the canvas's top-left. There AI focus shows no people, and in the full UI the faces of the people in the project sit in the left rail under Project. Each project keeps its own mode, on the desktop and in the browser, and keeps it through a rename: it returns in the mode you left it in, and a project you open for the first time takes the last mode you chose (remembered across launches); your very first launch opens in AI focus. On the desktop, AI focus replaces the project tabs with Home and a file switcher: the open file's name with a chevron, then one bar per agent working in this project, in its colour (tall when it works on this file, short when it works on another one; from six agents, five bars and a count). Clicking the name or the bars opens a menu: Agents working (the files agents are editing; opening one jumps once to where its agent works if that is off screen, and never follows it after), Files (your five most recent) and Search files (Cmd+P). Home shows all your project tabs; switch projects there or with Ctrl+Tab. |
| Toggle inspector sections | Cmd+/ | Collapse/expand all collapsible toolbar sections (the right-toolbar inspector groups) |
| Toggle left toolbar | Cmd+Shift+Left | |
| Toggle right toolbar | Cmd+Shift+Right | |
| Toggle bottom toolbar | Cmd+Shift+Down | |
| Toggle desktop icons | Ctrl+I | Hides/shows the macOS desktop icons (a real Finder toggle). Overlay mode only: it restarts Finder for a clean overlay screenshot, and a trigger in a normal studio window is refused (enter overlay mode first). macOS only: the command hard-returns off macOS, and the Ctrl+I chord is disabled on Windows (freed for Italic) |
| Clear all elements | (none) | Removes all elements from the active canvas (undoable). No shortcut, so a stray key never empties a canvas: use the canvas right-click menu (Canvas submenu) or the palette |

Passthrough mode is overlay-only. Cmd+\ hides ALL app chrome (the left / right / bottom toolbars plus the top strip) in both window modes; press it again to bring everything back. In overlay the top strip's tabs are already suppressed, so an overlay drawing surface stays clear. The hidden state is not remembered across launches: a reboot always restores the chrome.

**Agent cursors** (on by default; toggle via the palette "Toggle Agent Cursors" or Settings → Models → Agent cursors; persisted across restarts) adds multiplayer-style named cursors. Each AI agent working on the canvas gets a cursor (the same arrow as the user's own cursor, tinted in the agent's session color, matching its shimmer) that glides between the elements it touches, with a name tag. The cursor is present for the WHOLE turn, not just during edits: it appears (slightly dimmed) the moment the agent starts thinking (before its first edit), sits quietly near its last work (or mid-viewport on a first turn), and lifts to full strength when the agent edits or narrates. External agents driving Brilliant over MCP (e.g. Claude Code terminals) stay visibly present across their tool calls the same way: the cursor appears on the canvas they edited. An external agent never tells Brilliant it is done, so its cursor stays for a while after its last call (about a minute and a half after its last edit, about 15 seconds when it only read), then fades. If you switch to another canvas, the cursor stays with its work and reappears there when you switch back. Agents name themselves after the task at hand (e.g. "Meditation App", streamed via the same mechanism as chat titles), falling back to a stable per-session name like "Nova" or "Pixel" until the name arrives. With "Show Agent Thinking" enabled (sub-setting, on by default), the name tag extends into a small card where the agent's live commentary types out word-by-word at reading pace, subtitle-style (up to four scrolling lines); element references appear as clickable chips that select and zoom to the element. The cursor waits for its caption to finish before moving on, and if a response ends naturally the caption plays out before the cursor fades; stopping the chat removes both immediately. **Clicking an agent's cursor, name, or card opens its chat session** (the pointer shows a click cursor over it, and clicks never affect canvas content beneath). Optionally (sub-setting "Show Your Cursor Name", off by default) the user's own pointer carries a blue name tag baked into the native arrow cursor (zero lag); the name defaults to the local part of the activation email and can be changed in Settings → Models → Agent cursors → Displayed Name. All of these settings persist across restarts.
When an agent reads elements (a `read` or an export), the elements it gets back flash a brief top-to-bottom scan sweep, so you can see exactly what it is looking at.

If the window cannot be seen, press Ctrl+F: as a global hotkey it forces a return to studio mode and restores the saved window geometry.

# Editing

How a user manipulates elements directly on the canvas: selecting, moving, resizing, rotating, aligning, grouping, and so on. All actions below are performed by hand (mouse, handles, keyboard shortcuts, or the right-toolbar property fields). Shortcuts shown are macOS defaults; on Windows, Cmd maps to Ctrl.

Each part has its own key:

- `reference/editing/selection`: click selection, staying at depth, Select layer, multi-selection, marquee
- `reference/editing/hierarchy`: Enter, double-click, Escape, Tab; implicit and per-parent selection; visual feedback
- `reference/editing/measurement`: Alt+hover distance guides
- `reference/editing/movement`: drag, nudge, Alt+drag duplicate, auto-reparenting, snap and pixel grid, X/Y
- `reference/editing/resizing`: resize and corner radius handles, modifiers, auto layout, child pins, W/H
- `reference/editing/rotation`: rotation handles, keyboard rotation levels, flipping
- `reference/editing/scaling`: scale levels and skew
- `reference/editing/arrange`: alignment, distribution, z-order
- `reference/editing/layers`: group, frame, ungroup, auto layout wrap, rename, hide/show, lock
- `reference/editing/booleans`: boolean operations and masks
- `reference/editing/flatten`: Flatten (Cmd+Enter) per input
- `reference/editing/outline-text`: Outline Text and Flatten Text
- `reference/editing/clipboard`: copy, cut, and what gets copied
- `reference/editing/paste`: paste rules, external paste, paste in another project
- `reference/editing/paste-replace`: Paste to Replace, Copy/Paste properties
- `reference/editing/figma-paste`: pasting from Figma and its limits
- `reference/editing/duplicate`: duplicate, Alt+drag duplicate, delete
- `reference/editing/undo`: per-canvas undo, file explorer undo
- `reference/editing/undoable`: what is undoable
- `reference/editing/repair-fill-layout`: `repair_fill_layout`

# Keyboard Shortcuts

Press **Shift+?** to view shortcuts inside the app.

Shortcuts work on every keyboard layout: on a Latin layout (QWERTY, AZERTY, QWERTZ, Dvorak) a shortcut is the key that types its letter, on a non-Latin layout (Cyrillic, Hebrew, Arabic, Greek) it is the key at that letter's position on a US keyboard, so V is the Move tool on every layout.

## Limitations

- **No chord (multi-key) shortcuts**: Each shortcut is a single key combination (one key + optional modifiers). You cannot bind sequences like `Ctrl+K, Ctrl+C`. Use **Combos** (Cmd+Shift+M) to chain multiple actions behind a single shortcut.
- **Modifier-only behaviors are not remappable**: Hold-modifiers like Space (temporary hand tool), Alt+hover (measurements), Alt+drag (duplicate while moving), Shift+drag (constrain proportions or angle), and Ctrl+drag (scale mode during resize) are built-in and cannot be reassigned in the Shortcuts panel. Note: the **K** key toggles persistent scale mode as an alternative to holding Ctrl during resize.

- `reference/shortcuts/text`: text styling
- `reference/shortcuts/color`: quick colors, color picker, fill and stroke
- `reference/shortcuts/appearance`: effects, size levels, transparency, corner radius
- `reference/shortcuts/canvas`: zoom, grids and snapping
- `reference/shortcuts/window`: window and background
- `reference/shortcuts/files`: canvas management, file operations
- `reference/shortcuts/panels`: tabs and home, UI panels
- `reference/shortcuts/code-editor`: the code editor

- `reference/shortcuts/contexts`: activation contexts, running commands from the view, programmatic keybindings

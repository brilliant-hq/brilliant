# Styling

- `reference/styling/colors`: quick color shortcuts, color formats, typing a hex value
- `reference/styling/color-picker`: the picker's Custom and Library tabs, category row, swatches
- `reference/styling/eyedropper-tokens`: named colors, the eyedropper, token-preserving picks, color and opacity token bindings
- `reference/styling/fills`: adding and removing fills, solid, multiple, vector region and text fills
- `reference/styling/gradients`: linear, radial, angular and diamond gradients, the stop bar
- `reference/styling/image-fills`: image fills, image mode in the picker, formats, scale modes
- `reference/styling/shader-filter-fills`: shader, image filter and color adjust fills
- `reference/styling/strokes`: adding strokes, position, thickness, per-side widths, dash, caps, join
- `reference/styling/stroke-types`: stroke style types, multiple strokes, stroke on new shapes
- `reference/styling/blend-opacity`: blend modes at four levels, pass through vs normal, opacity
- `reference/styling/corners`: corner radius, per-corner radius, smoothing, circle arc and ratio

## Effects

Effects add shadows, glows, blurs, and texture. Brilliant has two parallel systems: see `reference/effects` (Liquid Glass: `reference/effects/liquid-glass`).

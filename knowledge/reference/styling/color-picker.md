# Color Picker

Open by clicking any color swatch (the small **color rectangle** on the left of any fill / stroke / effect / text-range / layout-grid row) in the right toolbar. The picker opens anchored to the right, focused on that target. There is also a global toggle: **Ctrl+C** (remapped to **Alt+C on Windows**) opens / closes the color selector for the current selection's fill or stroke.

The picker is as wide as the right toolbar. Its header holds two tabs, **Custom** and **Library**, and a close button. It opens on the tab you used last (until the app restarts); the arrow keys switch tabs while a tab is focused.

Custom tab components (top to bottom):
1. **Category row**: Solid, Gradient, Image, Shader, Effect, Filter (see below).
2. **Color field**, as wide as the picker. Left to right is saturation, top to bottom brightness. Press or drag; the round handle sits exactly on the picked color (at a corner it hangs half over the edge and can still be grabbed). One drag is one undo step. In image mode this slot shows the image with a Replace button (or a drop area when no image is placed yet), and the tracks and value field give way to the Fit menu and the image opacity field.
3. **Type row** (gradient, shader, effect and filter fills only), under the color field: a menu of the types in that category (hover a type to preview it on the canvas, click to apply, close the menu to cancel). A gradient's row has two lines: the type menu with, at the right, the gradient's **angle** ("90°" for left to right; type a number or drag on it to turn the gradient), **Flip** (reverses the stops) and **Rotate** (turns the gradient 90° clockwise), each one undo step; under them, the full-width **stop bar**: the selected stop is ringed and the color controls edit it, each stop's position shows under the bar; hover the bar to see where a new stop would go, click the bar to add one there, drag a stop to move it, drag it off the bar to remove it, or press Delete / Backspace (a gradient keeps at least two stops). A shader, effect or filter shows one small swatch per color of the fill (click one to edit that color). The fill's other settings (blend, shown or hidden, and the type's own parameters) are in the picker's **Settings** section at its bottom. A type with no color (background blur, color adjust, pixelate, posterize, noise / grain) shows only this row.
4. **Eyedropper button + tracks**. The eyedropper toggle on the left (highlighted while picking), then two thin tracks: the 360-degree hue spectrum on top and opacity (alpha 0%-100% for the focused color, over a checkerboard) below.
5. **Keyboard**. After clicking the field or a track, the arrow keys nudge it (1% saturation or brightness on the field, 1 degree of hue, 1% opacity; Shift for 10x), one undo step per press.
6. **Value field**: one field holding the format (click it for the Format menu), the value, and the opacity ("100%"). The Format menu lists Hex, RGB, HSL, HSB, OKLCH and CSS, each with the current color written in that format beside its name; hovering a format previews it in the field, and the picker keeps the format you chose the next time it opens. To copy the value, click it (the whole value selects) and press Cmd+C (Ctrl+C on Windows and Linux). For a gradient, the selected stop's position shows at the left of this row as a percentage: drag it, pick from its menu, or type a number (`25` or `25%`).
7. **Contrast line** (solid and gradient colors on fills, strokes and text): a dot and a line such as "4.5 : 1 on Card · AA", the contrast of the color against what is directly behind the element. When it names one solid backdrop, a dashed **AA** line in the color field marks where colors start to pass, and a drag near it snaps onto it (hold Option, or Alt on Windows and Linux, to move freely).
8. **Swatches** at the bottom: one grid of colors with a **Recent** | **On canvas** switch above it (a plain **Recent** heading when the canvas holds no other color). In image mode a **Recent** row of your recent images takes its place.

The **Library** tab lists the design system's color tokens: a search field, the pinned tokens, one scale bar per pinned palette, then every color token by group. Hover a token to preview it, click to bind it (one undo step) and close the picker (it stays open on a gradient stop, a shader color or a filter color); **+ New token** saves the current color as a token. See "Color Picker Sections" below.

The **category row** at the top of the Custom tab selects the fill type: one icon button per category (Solid, Gradient, Image, Shader, Effect, Filter; hover for the name), the current one highlighted. A click switches to that category's first type in one undoable step (Solid, Linear gradient, Image, the first shader, Liquid glass, Color adjust); clicking the highlighted one does nothing. The picker stays open on every category; the type row under the color area picks the exact type. Strokes show Solid, Gradient, Image and Shader; a text selection shows Solid and Gradient; the canvas background, layout guides and effect colors show no row. The type dropdown on the fill row in the right toolbar lists the same categories (Colors, Image, Shader, Effect, Filter). The picker reflows based on the current fill type.

## Color Picker Sections

The color picker includes additional sections below the main controls:

- **Library** (the second tab): the design system's color tokens. The search field stays at the top while the token list scrolls under it. Type to search by name (up and down arrows move the highlight, Return applies, Escape clears the search). **Pinned** lists the tokens the design system pins (or its `color.*` roles when it pins none), **Scales** shows one nine-step bar per pinned palette (click a step to bind it), and every other color token follows by group. Hover a token to preview it on the canvas; a click (or Return) binds it in one undo step and closes the picker, except on a gradient stop, a shader color or a filter color, where the picker stays open for the next one; the list never reorders under the pointer. Tokens stay bound through theme and mode switches. **+ New token** saves the current color as a new token in the design system file for the canvas's folder (everything else in the file stays as it was) and can bind the color to it; one undo removes it. A project without a design system can create one from the same tab. For how design systems and tokens are authored, see the design-systems knowledge files.
- **Swatches** (one section at the bottom): a small switch reading "Recent" | "On canvas · N" picks which colors the grid shows. **Recent** is the colors you applied, newest first, across sessions (up to 24). **On canvas** is every distinct color used on the active canvas (N is how many), shown as it looks in the canvas's current mode and brand, solids first then gradients, then by hue. When the canvas holds no color besides the one you are editing, the switch is replaced by a plain "Recent" heading. The picker remembers which one you chose until you quit the app. Click a swatch to apply it; the grid stays put while the picker is open. Hover a swatch to see its value.

In contexts that only support solid colors (canvas background, layout grid color, effect color, AI-input callback editing), gradients and shader fills are filtered out of the tokens and both swatch lists. A text-range color is not one of these: a range takes a solid or a gradient (its handles sit on the whole text box, the same as a fill gradient), only shader and image fills stay whole-element.

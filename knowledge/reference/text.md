# Text

Text is a regular element type. A text element is its bounding box plus a text payload; the same selection, move, resize, rotate, and flip operations apply to it as to any shape. Text color comes from fills (not strokes), and text also supports strokes (outlined text). All typography controls live in the right toolbar's Typography section when a text element is selected.

- `reference/text/create-edit`: creating text with the Text tool, entering, editing and exiting edit mode
- `reference/text/sizing`: Auto Size, Auto Height, Auto Width, Fixed, text in auto layout
- `reference/text/typography`: the Typography section, font family, font weight, italic
- `reference/text/typography-size-align`: font size, bold, italic, underline, strikethrough, alignment
- `reference/text/typography-paragraph`: line height, letter spacing, paragraph spacing, lists, case, truncation, OpenType, direction
- `reference/text/ranges`: styled ranges, hyperlinks, design tokens on text
- `reference/text/navigation`: shortcuts while editing, the right-click menu
- `reference/text/limits`: outline text and flatten, multilingual text and emoji, tips, not supported

# Color Picker

Open by clicking any color swatch or pressing **Ctrl+C**. The picker opens on that swatch's color. Clicking the same swatch again closes it, and clicking another swatch moves the picker to that color. The picker is as wide as the right toolbar.

## Layout (top to bottom)

- **Header**: two tabs, **Custom** and **Library**, and a close button (X) at the right. Custom holds everything below; Library holds the design-system color tokens (see **Library tab** below). The picker opens on the tab you used last (until the app restarts). With a tab focused, the left and right arrow keys switch tabs. The close button closes the picker, the same as Escape or clicking the swatch again. Drag the header's empty space to move the picker (a grip shows at the top of the header on hover); it stays there while it is open and opens fresh beside its swatch next time.
- **Category row**: one row of icon buttons for the fill type: Solid, Gradient, Image, Shader, Effect, Filter (hover a button for its name). The current type's button is highlighted. Clicking another button switches the fill to that category's first type in one undoable step: Solid, Linear gradient, Image, the first shader, Liquid glass, or Color adjust. The picker stays open on every category. A stroke shows four buttons (Solid, Gradient, Image, Shader), a text selection two (Solid, Gradient); the canvas background, layout grids and effect colors show none.
- **Color field**: a wide field as wide as the picker. Left to right is saturation, top to bottom brightness. Press or drag anywhere in it; the round handle sits exactly on the picked color, so at a corner it hangs half over the edge (and can still be grabbed there). One drag is one undo step.
- **Eyedropper + tracks row**: the eyedropper button (Ctrl+Shift+C; highlighted while picking) on the left, then two thin tracks: hue (the 360-degree spectrum) on top and opacity (0%--100%, over a checkerboard) below. Each round thumb sits exactly on its value.
- **Keyboard**: after clicking the field or a track, the arrow keys nudge it: the field by 1% saturation (left / right) or brightness (up / down), the hue track by 1 degree, the opacity track by 1%. Hold Shift for 10x. Each key press is one undo step. On very dark colors a press moves at least far enough to change the color.
- **Type row**: Between the color field and the tracks row, a gradient, shader, effect or filter fill shows a **type row**: a menu of the types in that category (hover a type to preview it on the canvas, click to apply, close the menu to cancel), and, for a gradient, the stop bar, otherwise one small swatch per color of the fill. Click a swatch to edit that color (the color field, tracks and value field then edit it); for a shader, Delete or Backspace removes the selected color (a shader keeps at least one). The fill's other settings (blend, shown or hidden, and the type's own parameters) are in the picker's **Settings** section at its bottom; the right toolbar's color rows have no expanded settings. A type with no color (background blur, color adjust, pixelate, posterize, noise / grain) shows only the type row.
- **Gradient stop bar**: the bar shows the gradient with a square per stop; the selected stop has a blue ring, and the color controls edit it. Hovering a stop outlines it (a stop can be dragged). Hover the bar to see where a new stop would go; click the bar to add a stop there (it takes the gradient's color at that point and becomes selected); drag a stop along the bar to move it; drag a stop down or up off the bar and release to remove it (removing one of the last two stops turns the fill into a solid color of the other, the same as Delete). Delete or Backspace removes the selected stop. Until you first add or remove a stop, a hint at the foot of the picker reads "Click the rail to add · drag off or Backspace to remove". The selected stop's position shows as a percentage at the left of the value row; drag it, pick from its menu, or type a number (`25` or `25%`).
- **Value field**: one field holding the format (click it for the Format menu: Hex, RGB, HSL, HSB, OKLCH, CSS, each previewing the current color), the value, and the opacity ("100%"). The picker keeps the format you chose the next time it opens. A token-bound color or opacity shows as a pill naming the token (a gradient stop, shader color, text span or effect too); click it to see the token in the Library tab. Changing only the opacity keeps the color's token, changing only the color keeps the opacity's token, and a typed hex or a clicked swatch binds a token only when it is exactly that token's color. Dragging in the color field or along a track never binds a token.
- **Contrast line** (text colors, solid or gradient, when something in the design sits behind the text): under the color value, a dot and a line such as "4.5 : 1 on Card · AA". It reads the contrast of the text color (at its opacity) against what is directly behind it: the layer it sits on, named by its layer name (where that layer is see-through, the canvas background shows through it too). Text straight on the canvas, and every other layer, shows no contrast line. The ratio shows rounded to one decimal; the level always comes from the exact ratio, so a shown 4.5 can still read AA Large. Levels: AAA (7 and above), AA (4.5), AA Large (3), Fails AA; the dot is green, orange or red. It updates live while you drag. When what is behind is not one solid color it reads "Contrast varies · image behind", "· gradient behind" or "· several backdrops" with a gray dot. Images, shaders, effects, filters, the canvas background, layout grids and effect colors show no contrast line.
- **AA line and snap**: when the contrast line names one solid backdrop, a dashed line in the color field marks where colors reach AA (4.5 : 1) at the current hue and opacity, with "AA" on the side that passes (on a mid-gray backdrop both a lighter and a darker line can show; when no color at that hue and opacity passes, there is none). Dragging the handle close to the line from the failing side snaps it onto the line, keeping your saturation, and shows "Snapped to AA"; releasing applies that color, which always passes. Hold **Option** (Alt on Windows and Linux) while dragging to move freely without snapping.
- **Image mode**: When an image fill swatch is clicked, the color picker switches to image mode with file selection, drag-and-drop, and Cmd+V paste support
- **Replace**: the Replace button on the picture opens a list of the project's files of that kind, the current one marked: for an image, the images you used recently, then the project's images; for a video, the project's videos with their length; for a motion fill, the project's films. Pick one to swap it in, or choose **Choose a file** to pick one from your computer (a video or film from outside the project is copied into the project's Assets or Motion folder). You can also drop a file on the picture. A swap keeps the fill's settings (an image keeps its fit and opacity; a video or motion fill keeps its speed, ends, fit and opacity) and is one undo.
- **Video and motion fills**: the Fills row of a video or motion fill shows its poster (the frame at its start, what the canvas shows at rest and what exports show) and, under it, the file name and the clip's length. Click the poster to open the picker on the fill: the poster with Replace, a small player (play or pause, a scrubber and the time) that plays the fill on the canvas without changing the file, and **Settings**: **Start** (seconds into the clip where it starts), **Speed** (1x is real time), **Ends** (Loop or Once) and **Fit** (Fill or Fit). To set the start visually, scrub the player to the frame you want and click **Set start to current frame** (the pin button beside Speed): that frame becomes the start and the poster everywhere. Each change is one undo. If a swap's new clip is shorter than the start, the start moves to the new clip's last frame and the picker says so.

## Bottom Section (Custom tab)

- **Swatches**: one grid with a "Recent" | "On canvas · N" switch above it (a plain "Recent" heading when the canvas has no other color). The picker remembers your choice until you quit the app.
  - **Recent**: the colors you applied, newest first (up to 24). Applying a color already in the list moves it to the front, and the same color at another opacity is its own entry. Previews, hovers, and gradient stop moves never add one. The grid holds still while the picker is open and shows your new colors the next time you open it.
  - **On canvas**: every distinct color used on the canvas, as it looks in the current mode and brand. Clicking one applies it and adds it to Recent; the grid does not move under the cursor.

## Library tab

The Library tab lists the project's color tokens; clicking one (or pressing Return on the highlighted one) binds the color to it and closes the picker. On a gradient stop, a shader color or a filter color the picker stays open, so you can go on to the next stop or color.

- **Search**: type to filter tokens by name. Results are grouped (Pinned, each pinned palette's scale, then the rest by group). Up and down arrows move the highlight, Return applies it, Escape clears the search (a second Escape closes the picker). With no match the picker says so; **Search all colors** also looks in the palettes the design system hides, and **Create "<name>" from <hex>** starts a new token with that name.
- **Source menu** (next to the search, only when there is more than one): pick which design system's tokens to show, the project's base or one of its brands, each with its token count.
- **Pinned**: the tokens the design system pins (its `pin:` list, in that order), or its `color.*` roles when it pins nothing. The token the color is bound to is highlighted; opening the Library from the token pill scrolls to it.
- **Scales**: one bar per pinned palette, its nine steps from lightest to strongest; click a step to bind it. The bound step is ringed.
- **More colours** (only when the design system has a `hide:` list): what `hide:` tucks away, always open below Scales, in `hide:` order. A hidden palette is its name over its nine-step bar (hover a step to preview it, click to bind it, like Scales); any other hidden color is a plain token row.
- Below, every color token, grouped by its first name segment.
- Hovering a token previews it on the canvas, moving away puts the color back, and a click applies it in one undoable step. The list does not reorder when you pick.
- **+ New token** (next to Pinned): saves the current color as a new token. Name it (a free name like `color.new` is suggested), check where it saves (the design system file for this canvas's folder, for example `Styles/default.ds`), and choose whether to bind this fill, stroke or stop to it (on by default). Create adds one line to that file and keeps everything else in it as it was; one Cmd+Z removes the token and puts the color back. A name already in use, or one that is not a valid token name, is refused with the reason. A library's design system can't be changed from here. On the Library tab a source chip beside the search groups "This project" brands and "Libraries" brands (by handle, each with its color-token count) and ends with "Add library…".
- **No design system yet**: **Create design system** adds Brilliant's default design system to the project; **or save <hex> as the first token** creates a design system holding just that color, as `color.primary`, and binds the color to it.

## Eyedropper (Ctrl+Shift+C)

Toggles the eyedropper / color-pick mode. Cursor follows the pointer with a magnified pixel-grid loupe; click anywhere on the screen to sample that pixel's color into the active swatch. Esc cancels (see Escape Behavior (Context-Aware) in `reference/shortcuts/selection`).

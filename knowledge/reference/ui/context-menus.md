# Context Menus

**Right-click on element** (in order): Select layer (every layer under the cursor, topmost first, nested ones indented; choosing one selects it and the layers panel shows it), Select This Item + Add to Selection (if not already selected), Cut, Copy, Copy as (PNG, PNG @2x, PNG @4x, WebP, SVG, HTML, React, CSS, Blueprint), Copy element id, Send to (Figma; enabled only when the Figma plugin is paired), Paste, Duplicate, Delete, Rename, Group/Ungroup/Add Auto Layout + Operations submenu (Union, Subtract, Intersect, Exclude, Mask) when 2+ elements, Component submenu (Create Component, Create Instance, Detach Instance, Go to Master, Reset Overrides, Push Overrides to Master, Select Instance for a layer inside an instance) when applicable, Bring to Front, Bring Forward, Send Backward, Send to Back (four rows directly in the menu, not a submenu), Align & Transform (for multi-selection: Align Left/Right/Top/Bottom, Align Horizontally/Vertically, Distribute Horizontally/Vertically; always: Flip Horizontally/Vertically, Scale Up/Down, Fit to Parent), Select Parent (for nested elements), Toggle Clip Content (for frames), Remove Background or Restore Background (for an element with an image fill: whichever applies; it acts on every image in the selection), Add Outline (beside Restore Background; on a photo whose background is still there it reads "Add Outline (remove the background first)", disabled), Export as (PNG, PNG @2x, PNG @4x, SVG, Replay), Text submenu (for text elements: Bold, Italic, Underline, Align Text Left/Center/Right, Size Auto Size/Auto Height/Fixed Size, Switch Font), View (Zoom to Elements, Center on Elements).

**Copy element id** (next to Copy link, on every platform; also a keybindable command "Copy element id" in the palette) puts the selected element's id on the clipboard as plain text, one id per line for a multi-selection, and confirms with a "Copied element id" toast. Paste that id into a Claude Code prompt to point the agent at exactly that element: it is the same id `read` returns and an `edit` targets, so the agent can act on the frame by id instead of by description.

**Right-click with selection** (items selected, click on selected element): Shows "[N] items selected" header, then Select layer, then the same structure as element menu but operating on the full selection. Includes Canvas submenu (Toggle Background, Whiteboard, Blackboard, Toggle Alignment Guides).

**Right-click inside a text you are editing**: Cut, Copy, Paste, Select All; Bold, Italic, Underline, Strikethrough (checked when the selected text has them); Font (Font..., Weight, Bigger, Smaller), Text Color..., Link...; Transformations (Upper Case, Lower Case, Title Case), Align (Left, Center, Right), List (Bulleted, Numbered). Every row acts on the selected text and shows its shortcut when it has one; with no selection a style row does what its shortcut does there (Bold bolds the whole text), Cut and Copy and the Transformations are disabled, and Paste is disabled with an empty clipboard. On macOS this is the native system menu; on Windows and the web it is Brilliant's own menu, where Escape or a click outside closes only the menu and typing closes it and types. Either way the edit stays open with your selection. On a word marked as misspelled, the corrections, Ignore and Add to dictionary come first (see `reference/ui/spell-check`).

**Right-click on empty canvas**: Select layer (when a layer is under the cursor, such as the body of a top-level frame), Paste, Select All, Create submenu (Text, Rectangle, Circle, Line, Arrow, Pencil, Frame), Canvas submenu (Toggle Background, Whiteboard, Blackboard, Toggle Alignment Guides, Clear All Elements), Import..., Export as (PNG, PNG @2x, PNG @4x, SVG, Replay).

**File explorer right-click on files**: Open, Rename, New Canvas, New Folder, Cut, Copy, Paste, Duplicate, Delete, Show in Finder, Copy Filename, Copy Relative Path, Copy Absolute Path.

**File explorer right-click on folders**: Expand/Collapse, Rename, New Canvas, New Folder, Cut, Copy, Paste, Duplicate, Expand All, Collapse All, Delete, Show in Finder, Copy Relative Path, Copy Absolute Path.

**File explorer right-click on empty space**: Select All, New Canvas, New Folder, Paste, Expand All, Collapse All.

**File explorer in the browser**: where the project lets you manage files, the menus above, without Show in Finder (or Show in Explorer) and Copy Absolute Path, which need a disk. Cut and Paste work on every row (a cut item moves on Paste, the same way a drag moves it). Copy and Duplicate work on canvases only: a plain file or a folder offers Cut but no Copy or Duplicate, and a selection holding one offers neither. There is no New File... row. In a view-only project, files and folders have no right-click menu and empty space offers only Expand All and Collapse All.

**Layers explorer right-click on element**: Select (if not selected), Rename, Remove Background or Restore Background (for an element with an image fill), Add Outline (on a photo whose background was removed), Bring to Front, Bring Forward, Send Backward, Send to Back (four rows directly in the menu, not a submenu), Align & Transform (Center Horizontally, Center Vertically, Flip Horizontally/Vertically, Scale Up/Down, Fit to Parent), View (Zoom to Elements, Center on Elements), Copy, Cut, Duplicate, Text submenu (for text elements), Shape options (for rectangles), Color submenu, Delete.

# Right Toolbar (Property Inspector)

Flush against the window's right edge at full height, 280 px wide by default (240 px at Compact density). Drag its left edge toward the canvas to make it wider, up to 400 px; it never gets narrower than its default. The width you set is remembered the next time you open Brilliant. Toggled off (Toggle Right Toolbar, Cmd+Shift+→, or the palette) it hides completely; the same shortcut brings it back. Sections appear dynamically based on the current selection and tool. The inspector shows only what is selected: hovering an element on the canvas never changes it. While you drag a selection rectangle, it shows the elements the rectangle will select, and after release, the selection. With nothing selected it shows the canvas and the defaults for new elements. Menus preview on hover where seeing the result is the point (colors, typography, corner radius, layout guides, design system brand and modes, and a frame's device preset sizes): moving off the menu or pressing Escape puts the old value back, and a click applies it as one undo step. Position, the W and H size presets, the parent type, and the zoom menu apply only when you pick a row. Only one menu is open at a time anywhere in Brilliant: opening a menu (an inspector menu, a toolbar or "…" menu, a right-click menu) closes the one already open, and a preview it was showing goes back. A menu inside another surface, such as a menu in the color picker, leaves that surface open.

**The selection header** opens the panel. Its first line is the selection's icon and name (double-click the name to rename the layer); the second line says what it is and where it sits ("Frame · in Card", "Auto layout · in Card", "Instance of Button · in Hero", "Text · inside Button", "3 layers" over "Mixed · in Card"), and the place is a link that selects it. With nothing selected it names the canvas. On the right, **…** toggles all sections (Cmd+/), and on a component instance a button beside it goes to the main component (or, inside an instance, selects the instance). In the desktop app on macOS and Windows Share and the people on the project are in the top bar (`reference/ui/top-toolbar`) and your account avatar is at the foot of the nav rail, so the header row described next is not shown there; the browser editor keeps that row above the selection header, without its "…" menu.

The header row reads, left to right, **account avatar, presence toggle, Share button, a hover-revealed "…" options menu, then (on the right) the zoom-level field**. The avatar, presence toggle, and Share stay visible whenever they apply; the "…" menu fades in on hover; the zoom field is always there. Each item shows only when it's relevant:

- **Account avatar:** the account you are acting as: your own photo (or initial) normally, or the team's square avatar when you are acting as a team (the same identity the home avatar shows). Hover opens the account menu (email/identity, plan, "Switch Account" / "Sign out", "Open Settings -> Account", and "Project settings" for a cloud project). When you're signed out of a cloud/web project the avatar and the Share button collapse into a single compact **"Sign in"** button that stands in for both, unless you are editing a local copy (see Share below), where the local-copy button (**Sign in** signed out, **Open fullscreen** on the home page) keeps that slot instead. A purely local project with no account shows no avatar (a quiet header).
- **Presence sharing:** in a live session, toggles whether others see your cursor and viewport.
- **Share** (text button, one word for both states): for a published project it copies a shareable link to the current canvas straight to the clipboard (tooltip "Copy Link", a toast confirms), and if elements are selected the link deep-links to that selection. For a project with no shareable link yet (an unpublished desktop folder) it opens Settings -> Project at the publish flow instead (tooltip "Share this project…"), and never publishes by itself. On a normal project it's available in the web app, and on desktop it shows whenever you're signed in (signed out, it folds into the "Sign in" button described above). While you are editing a **local copy** (a playground scratch, or a public project you started changing) this slot instead depends on where you are: in the editor on the brilliant.design home page it reads **Open fullscreen** and turns that editor into the full playground in place; signed out it reads **Sign in** (signing in on the playground keeps what you made as your project); signed in it reads **Save a copy** and keeps that copy as your own project. The same copy-link action is also on the top-toolbar breadcrumb and the canvas right-click menu.

While dragging a selection that touches many elements, sections auto-collapse to stay responsive, then re-expand when the drag ends.

| Action | Shortcut |
|--------|----------|
| Toggle right toolbar | Cmd+Shift+→ |
| Expand or collapse all sections | Cmd+/ |

## Interactive Fields

Clicking into a field (numeric, or a hex color input) selects its whole value at once, so typing replaces it; click again inside the field to place the caret, double-click to reselect the whole value, and Tab to the next field (it selects all too). A number field scrubs from its leading symbol only (the X, the W, the corner radius icon, as in Figma): hover the symbol for the left-right cursor and drag it to scrub (one undo step). Everywhere else the field is a text input: the text cursor, a click edits, a drag selects text. A field with no leading symbol (an opacity percentage, for example) does not scrub; type its value, step it with the arrow keys or pick from its menu.

**Color rows** (fills, strokes, selection colors, gradient stops, shader colors, the canvas background, effect colors, layout grids) read as a swatch button followed by the color's hex, then its opacity. The whole swatch button opens the color picker; clicking it again closes the picker. Hex values show as six digits without a leading "#" (for example `3366FF`); typing a hex with or without "#" works. The picker's copy button still copies the hex with "#". An expanded gradient fill lists one row per stop: its position (0 to 100), its color (swatch and hex) and its opacity, with a "-" button to remove the stop.
